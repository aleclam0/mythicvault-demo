# MythicVault — Live Demo

### [▶ Launch the live demo](https://aleclam0.github.io/mythicvault-demo/)

An app for tracking a sports card portfolio with 3D rendered graded-slab showcase.

> **No sign-up required.** The demo runs entirely in your browser with seeded sample data.

## What you can try

- **Dashboard** — portfolio summary widgets, recent adds, and highest-value card.
- **Collection** — responsive grid / dense list, live filters (type, status, grader), rich search, and sorting.
- **Card detail** — full record view in a mobile bottom sheet / desktop drawer, with edit & delete.
- **Fast manual entry** — add ungraded or graded cards in a single dialog (`⌘/Ctrl + N`).
- **Portfolio assistant** — ask questions about your collection, answered instantly in-browser.
- **Slab Showcase** — a fullscreen 3D graded-slab experience: drag to rotate, flip, and a looping auto-showcase mode.

## About this build

This is a **static, backend-free export** of MythicVault. Your data lives only in your browser's `localStorage` — clearing site data resets the demo.
